Entry for the [Worst Superpower](https://make.fun/c/u-suroto-worst-superpower-461dcdbe) bounty on make.fun: invent the most useless superpower in one line of at most 140 characters.

## The entry

> I can read minds, but only the thoughts of pigeons, and only about crumbs.

74 characters, one line. Mind-reading, made worthless by its scope: the only minds it reaches belong to pigeons, and the only thing they ever think about is crumbs.

## How it works

`main.py` (Python 3, no dependencies) writes the line to `/output/entry.txt`, then reads it back and verifies the gate: exactly the entry line, a single line, 1–140 characters, not only whitespace.
